# Uploading non-image data to OMERO

To use non-image data as input for your JIPipe workflows, they need to be uploaded to the OMERO database. The fastest and easiest way to do so is via the OMERO webclient. Simply attach the files to a dataset or project you have access to. This is done the same way as [uploading workflow files](Uploading-workflows-to-OMERO.md): select a dataset or project and <b>go to General → Attachments in the right panel.</b> Click the <b>+</b> to attach a file.

All files available to your OMERO group will be listed in the relevant input node.

> After uploading new data, you need to refresh the page to update its contents.
